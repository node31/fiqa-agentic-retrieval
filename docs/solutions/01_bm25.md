# Solutions: bm25

Try the exercise before reading. Several answers point to *your own* run output, because the numbers are hardware-dependent.

**1.** The tf-part is tf(k1+1)/(tf+k1·norm) ≤ k1+1 = 2.2. Repeating a term 100× gives at most 2.2× the weight of the IDF, versus 100× in raw TF-IDF, so stuffing stops paying after a few occurrences.

**2.** With k1 = 0 the tf-part is tf·1/tf = 1 for every doc containing the term: BM25 becomes 'sum of IDFs of matched terms' (binary match), so docs a and b tie for 'loan' (both 0.470), with order broken by doc id.

**3.** IDF = ln(1 + 0.5/(N + 0.5)) ≈ 0.5/N, which is about 0 (8.7e-6 for N = 57,638). A word in every document carries no evidence.

**4.** Answer depends on your run; record it. Expectation: FiQA lengths are highly skewed (median 65 tokens, long tail to thousands), so b in 0.6–0.8 usually wins; b = 0.3 over-rewards long rambling answers.
