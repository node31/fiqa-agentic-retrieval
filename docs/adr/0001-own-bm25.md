# ADR 0001: Write BM25 ourselves on scipy sparse matrices

**Status:** accepted

## Context
Part A needs BM25, and Part B needs global corpus statistics injected at query time plus live upserts/deletes.

## Decision
Own `BM25Index`: CSC base segment + dict delta segment + alive mask; `search(terms, k, stats)` accepts global stats.

## Alternatives considered
rank_bm25 (no deletes, scores all N docs per term), Pyserini/Lucene (JVM; hides the statistics we need to control), Elasticsearch (forbidden: hides sharding).

## Consequences
+ exact control of IDF for sharding; 1.2 ms p50; matches published BEIR BM25 range (dev nDCG@10 0.264). − no compression or skip lists; compaction not implemented (drill 5); O(N) score array per query (breaks at ~10M docs/shard).
