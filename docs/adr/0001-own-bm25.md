# ADR 0001: I wrote BM25 myself on scipy sparse matrices

Status: accepted

## Context
Part A needs BM25. Part B needs two things on top: global corpus statistics injected at query time, and live upserts and deletes.

## Decision
I wrote `BM25Index` (`src/retrieval/bm25.py`): a CSC base segment, a dict delta segment for new writes, and an alive mask for deletes. `search(terms, k, stats)` accepts global stats from the router.

## Alternatives considered
| Option | Why I rejected it |
|---|---|
| rank_bm25 | No deletes, and it scores all N docs per term |
| Pyserini / Lucene | Runs on the JVM and hides the statistics I need to control |
| Elasticsearch | The assignment forbids it, and it would hide the sharding I had to build |

## Consequences
I control IDF exactly, which sharding needs. BM25 runs at 1.2 ms p50, and dev nDCG@10 0.264 is inside the published BEIR BM25 range. The costs: no compression or skip lists, no compaction (not built), and an O(N) score array per query, which breaks at about 10M docs per shard.
